# เว็บสีสนุก — คู่มือเริ่มต้น GitHub

โปรเจกต์นี้เป็นเว็บระบายสีสำหรับเด็ก มีภาพจรวด ผีเสื้อ และไดโนเสาร์ สามารถวาดด้วยเมาส์หรือหน้าจอสัมผัส ดาวน์โหลดภาพ และบันทึกคอลเลกชันไว้ในอุปกรณ์ได้

## นำโค้ดขึ้น GitHub

1. สมัครหรือเข้าสู่ระบบที่ https://github.com
2. กดปุ่ม **New repository**
3. ตั้งชื่อ `colorful-kids-studio` เลือก **Public** แล้วกด **Create repository**
4. ติดตั้ง GitHub Desktop จาก https://desktop.github.com
5. แตกไฟล์ ZIP นี้ แล้วเปิด GitHub Desktop
6. เลือก **File > Add local repository > Choose** และเลือกโฟลเดอร์ `colorful-kids-studio`
7. หากโปรแกรมถาม ให้เลือก **Create a repository**
8. ที่ช่อง Summary พิมพ์ `สร้างเว็บระบายสีเวอร์ชันแรก` แล้วกด **Commit to main**
9. กด **Publish repository** และเลือก repository ที่สร้างไว้

## เปิดเว็บบนเครื่อง

ต้องติดตั้ง Node.js เวอร์ชัน 22 ขึ้นไป จากนั้นเปิด Terminal ในโฟลเดอร์นี้แล้วใช้คำสั่ง:

```bash
npm install
npm run dev
```

## หมายเหตุเรื่อง GitHub Pages

โค้ดเวอร์ชันนี้ใช้ React/Vinext และมีขั้นตอน build สำหรับเซิร์ฟเวอร์ จึงยังไม่ควรเปิด GitHub Pages จากโฟลเดอร์โดยตรง เพราะหน้าเว็บจะไม่ทำงานครบถ้วน GitHub ยังใช้เก็บและจัดการ source code ได้ตามปกติ ส่วนการเผยแพร่สามารถเชื่อม repository ไปยังผู้ให้บริการ hosting ที่รองรับ framework หรือแปลงเป็น static site สำหรับ GitHub Pages ในขั้นถัดไป

## การเก็บคอลเลกชัน

ผลงานถูกเก็บใน Local Storage ของเบราว์เซอร์ จึงอยู่เฉพาะอุปกรณ์และเบราว์เซอร์ที่บันทึก หากล้างข้อมูลเว็บไซต์หรือเปลี่ยนเครื่อง คอลเลกชันจะไม่ตามไปด้วย
